# Fallback assets

Use this folder to park artifacts that are not currently used in Hefaistos but may be handy later.

- MITRE ATT&CK Navigator: We now embed the hosted Navigator (`https://mitre-attack.github.io/attack-navigator/enterprise/`). If you ever need to restore a local bundle, re-download a Navigator release and place it under `fallback/navigator/` instead of shipping it in `frontend/public/`. Refer to Docs/ATTACK_NAVIGATOR_SETUP.md for local run instructions.
