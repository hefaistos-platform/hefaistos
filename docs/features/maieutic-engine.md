# Maieutic Engine

## Purpose
Explain the guided Socratic assistant workflow for refining detection hypotheses into actionable outputs.

## Audience
Analysts and detection engineers using guided authoring support.

## Prerequisites
A Workbench context and access to AI-enabled features.

## Steps / Workflow
1. Start Maieutic from Workbench.
2. Progress through Hypothesis, Interrogation, Robustness, Playbook, and Review stages.
3. Import validated output back into Workbench fields.

## Validation / Expected result
The workflow produces structured, reviewable content mapped to Workbench sections.

## Troubleshooting
If questioning loops or context quality degrades, review challenge mode and input completeness.
