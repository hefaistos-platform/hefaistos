# Detection Workbench

## Purpose
Describe the Workbench as the primary environment for detection engineering lifecycle execution.

## Audience
Analysts, reviewers, and detection engineers.

## Prerequisites
Authenticated user with role allowing Workbench access.

## Steps / Workflow
1. Define detection strategy and ATT&CK alignment.
2. Build technical context and detection logic.
3. Use AI and supporting workflows to refine rules.
4. Submit for review and move through lifecycle states.

## Validation / Expected result
Workbench contains complete detection content ready for peer review and export.

## Troubleshooting
If sections are hidden or blocked, review visibility policy and required fields.
