# Query Editor

## Purpose
Explain supported query languages, autocomplete behavior, and validation in the Workbench editor.

## Audience
Analysts and engineers authoring detection logic in supported formats.

## Prerequisites
Workbench access and selected detection format.

## Steps / Workflow
1. Choose supported language tab (KQL, EQL, SPL, WAZUH, AQL).
2. Use trigger characters or manual autocomplete shortcuts.
3. Review syntax validation feedback and adjust query content.

## Validation / Expected result
Editor provides language-appropriate suggestions and backend validation markers.

## Troubleshooting
If autocomplete/validation is missing, verify auth state and backend availability.
