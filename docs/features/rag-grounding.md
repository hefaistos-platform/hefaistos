# RAG Grounding

## Purpose
Document retrieval-augmented grounding for language-specific rule generation quality.

## Audience
Detection engineers, AI feature operators, and connector maintainers.

## Prerequisites
Configured Qdrant service and repository template sync setup.

## Steps / Workflow
1. Configure repository RAG sync settings.
2. Ingest template datasets by supported file types.
3. Generate or improve rules with language-aware retrieval context.

## Validation / Expected result
Generated rules show improved syntax/schema consistency and reduced hallucination patterns.

## Troubleshooting
If retrieval quality is poor, verify dataset quality, language attribution, and sync health.
