# Local Development

## Purpose
Provide baseline setup path for developing HEFAISTOS locally.

## Audience
Backend/frontend contributors and maintainers.

## Prerequisites
Development dependencies and Docker runtime available.

## Steps / Workflow
1. Prepare repository and environment files.
2. Start development services and workers as needed.
3. Use GraphQL endpoint and local UI for iterative testing.

## Validation / Expected result
Local environment runs with working frontend, backend, database, and queue services.

## Troubleshooting
If local startup fails, validate env variables, secret files, and compose profile selection.
