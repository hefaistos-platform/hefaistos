# Contributing

## Purpose
Provide contributor workflow expectations for safe, reviewable changes.

## Audience
All repository contributors.

## Prerequisites
Access to repository, local development setup, and role-appropriate review permissions.

## Steps / Workflow
1. Follow repository coding and workflow conventions.
2. Run relevant tests and validation checks.
3. Submit changes with clear commit messages and review context.
4. Resolve review feedback and compliance checks.

## Validation / Expected result
Contributions pass checks and align with maintainers' review standards.

## Troubleshooting
If PR gates fail, inspect workflow output and dependency/license policy requirements.
