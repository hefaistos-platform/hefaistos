# Testing

## Purpose
Document standard backend/frontend test execution paths.

## Audience
Contributors validating changes before submission.

## Prerequisites
Local development environment running and dependencies installed.

## Steps / Workflow
1. Run backend tests.
2. Run frontend tests.
3. Generate coverage where required.

## Validation / Expected result
All relevant tests pass and regressions are not introduced.

## Troubleshooting
If tests fail, isolate service-specific failures and re-run with focused scopes before full suite.
